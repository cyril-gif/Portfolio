# Kofi Adjei - Professional Portfolio

A complete, production-ready personal portfolio website for a Full-Stack Web Developer & Business Support Specialist.

## Features

- 🎨 Clean dark UI with electric blue accent
- 📱 Fully responsive (mobile-first)
- 🚀 Smooth scroll animations with Intersection Observer
- 📝 Contact form with MongoDB backend
- 💻 Hybrid skill presentation (Dev + Office)
- ⚡ Vanilla JS, no heavy frameworks

## Tech Stack

- **Frontend**: HTML5, CSS3, vanilla JavaScript (ES6+)
- **Backend**: Node.js, Express.js (ES modules)
- **Database**: MongoDB with Mongoose ODM

## Setup & Installation

### Prerequisites

- Node.js (v16 or higher)
- MongoDB Atlas account (or local MongoDB installation)
